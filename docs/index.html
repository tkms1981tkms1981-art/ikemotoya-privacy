プライバシーポリシー

池本屋（Ikemotoya）は、Threads 自動投稿システムの利用にあたり、以下の通り個人情報を扱います。

1. 収集する情報について

本アプリは以下の Threads API 権限のみを使用します。

  • threads_basic
  • threads_content_publish

これらは「投稿の作成」「自分のプロフィール情報の取得」にのみ使われます。

2. 収集した情報の利用目的

  • 自動投稿の実行
  • アプリの動作に必要な認証処理

3. 第三者提供について

取得した情報を第三者へ提供することはありません。

4. データ削除について

ご利用者のリクエストに応じて、保存されている情報を削除します。
