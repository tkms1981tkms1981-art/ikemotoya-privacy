プライバシーポリシー

最終更新日：2025年11月26日

Ikemotoya Threads Bot（以下「当アプリ」）は、ユーザーの個人情報を適切に取り扱うため、以下の通りプライバシーポリシーを定めます。

1. 取得する情報

当アプリは、Threads API を利用するために以下の情報を処理する場合があります：

  • ユーザーが Threads 上で公開した投稿データ
  • アプリ操作に必要なアクセストークン

これらの情報は投稿の自動化のみを目的として使用し、第三者に提供しません。

2. 情報の利用目的

  • 池本屋の公式アカウントにおける Threads への自動投稿
  • 投稿管理および運用改善
  • アプリの動作に必要な認証処理

3. 第三者への提供

当アプリは、法令に基づく場合を除き、ユーザーの情報を第三者へ提供しません。

4. データの保存期間

アクセストークンや投稿データは、API 利用のために必要な期間のみ保持され、不要となった場合は速やかに削除されます。

5. セキュリティ

当アプリは適切なセキュリティ手段を講じ、個人情報の漏洩・改ざん・不正アクセス防止に努めます。
